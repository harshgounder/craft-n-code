## The mechanism: a three-step path

1. Ingest. Emails, tickets, messages, documents land in one inbox. Zero external services, runs fully local.
2. Decide. The engine dedupes, summarizes, ranks, and proposes actions with an evidence panel behind every proposal. No silent autonomy: every action is typed, every tool call is logged.
3. Approve and audit. A human approves or rejects each proposed action. Every decision, timestamp, and provider outcome is recorded in a replayable trace.
