# D³ Fest 2022  -  Full Hackathon Problem Statements (d3nov.netlify.app)

Compiled: 2026-08-13 | Source: d3nov.netlify.app (D³ Fest 2022 site, Nov 12-15 2022, Tech Society + E-Cell)

## The fest

- D³ Fest 2022, Nov 12-15 2022, IIIT Bhubaneswar. Tech Society + E-Cell. Prizes ₹25K+.
- Hackathon registered on DevPost. Infosec (cyber club) reopened under Mr. Debashish Jena (Registrar, IIIT-B).
- 4 days: Opening Ceremony, Campus Innovators (business hackathon), Microsoft After Party, Hackathon, Cyber Hunt, Case or Face, Biz-Hunt (E-Cell + NAPS), Code-Thru++ (ICPC format), Closing Ceremony.

## The 9 hackathon problems (VERIFIED, full text)

| ID | Problem | Tasks |
|---|---|---|
| D3h01 | Code snippet sharing platform (like a code-focused social feed, text snippets with syntax highlighting, like/comment) | T1: share + per-snippet page; T2: reactions + suggest edits |
| D3h02 | Hostel management: room allocation/reallocation, empty rooms, students per institute per building, report generation (student/building/floor wise) | T1: online leave application with status; T2: complaint system (water, hygiene, electrical) |
| D3h03 | All-in-one smart campus app: cleanliness, lost & found, canteen orders, event notifications, vehicle/tool sharing, voting | T1: vehicle/tool sharing; T2: voting system |
| D3h04 | Bill split app: track expenses, split among friends | T1: monthly expenditure graph; T2: notification after split |
| D3h05 | Mess management: admin dashboard (coupons, menu, pricing), students buy coupons, centralized platform | T1: QR codes per meal; T2: Razorpay integration |
| D3h06 | PM2.5 prediction: EDA + feature engineering + regression/classification models (sklearn), deploy via Flask | T1: cross validation; T2: hyperparameter tuning + docs |
| D3h07 | IRCTC ticket automation with Selenium (Tatkal purchases) | T1: web driver inputs via APIs (FastAPI/Flask/Django/Node); T2: automate IRCTC food ordering |
| D3h08 | Crypto crowdfunding: creators post ideas, crowd funds with crypto/ETH, MetaMask wallets | T1: MetaMask; T2: IPFS/Pinata decentralized storage (plus) |
| D3h09 | On-chain event ticketing: organizers create events, attendees buy tickets with crypto, smart contracts deployed + verified on testnet (Goerli/Sepolia), frontend via ethers.js/web3js/Moralis | T1: MetaMask; T2: IPFS/Pinata (plus) |

## Lineage insights (2022 → 2026)

- **D3h09 (on-chain event ticketing) is the DIRECT ancestor of 2025 Challenge 1 (NFT event ticketing)**  -  same problem, 3 years later, re-skinned for the national stage.
- **D3h05 (mess management) → 2026 night canteen**  -  the food-ordering obsession is a 4-year tradition.
- **D3h06 (PM2.5 ML prediction) → the AI/ML track DNA**  -  sklearn + Flask deployment was the 2022 bar; 2026 expects Gemini/Llama-grade AI.
- **D3h02 (hostel management) → PS-01 Rewind the Legacy**  -  "outdated tool your campus depends on" is literally the hostel/mess/campus problem family.
- **D3h07 (IRCTC automation) → the security/automation DNA**  -  Selenium automation was a sanctioned problem in 2022.
- **The 2022 problems were CAMPUS-LIFE + WEB3 + ML.** The 2025 problems were WEB3 + AI + SECURITY. The 2026 tracks (Legacy, Night Ops, Signal/Noise, Open, Hardware) are the CAMPUS-LIFE family reorganized + hardware added.
- **Pattern: the organizers recycle problem families every 2-3 years with new tech.** The 2026 questions will likely be 2022/2025 problems re-skinned with 2026 sponsor tech (Gemini, Llama, Firefly, enterprise AI).
