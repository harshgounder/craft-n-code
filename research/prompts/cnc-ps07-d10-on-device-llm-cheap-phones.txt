## Core line
Statement-faithful research for the edge-AI mesh architecture: cheap sensor nodes,
farmer phone as offline AI hub (small quantized LLM), continuous learning loop
(server fine-tunes, phone adapts), and the predictive statistics underneath. This
run maps what exists, what is real vs marketing, and what a prototype can demo.

Research the real state of running small LLMs on cheap Android phones offline:
- Which small models actually run on sub-Rs 15,000 Android phones (4-6GB RAM): Gemma 2 2B, Qwen 2.5 1.5B/3B, Llama 3.2 1B/3B, Phi-3 mini, TinyLlama, SmolLM2, any 2025-2026 releases (Qwen 2.5, Gemma 3 1B, etc). Which are viable for Hindi/Odia (tokenizer quality, Indic language capability).
- Quantization reality: Q4/Q8 sizes, RAM footprint at runtime, tokens/sec on real devices (llama.cpp / MLCChat / ExecuTorch benchmarks), thermal and battery behavior during sustained inference.
- Offline stacks: llama.cpp, MLC-LLM, ExecuTorch, mediapipe LLM inference, which is mature on Android, APK size, no-Google-play constraints.
- Phone-side adaptation reality: what CAN run on-device (RAG over local rule JSON, prompt adapters, online classical ML) vs what CANNOT (real-time fine-tuning of LLM weights). State the physics honestly.
- Any published deployments of on-device LLMs in Indian agriculture or rural settings.
- Price list: which concrete phone models in India at what price can run which model at what speed.
