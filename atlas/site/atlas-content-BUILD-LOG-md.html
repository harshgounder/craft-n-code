THE RULES THAT SURVIVED (hard rules)

  1. All source code is written by opencode CLI. Hermes is the architect

and reviewer: writes briefs, audits diffs, tells opencode what is

right and wrong, runs tests, commits. Hermes never writes source

code itself.

  1. No em dashes in any output, file, doc, or comment. No AI-tell words.
  2. Research waves run ONE BY ONE, never parallel fan-out.
  3. The demo has zero uncontrolled dependencies. LLM, cached, or offline,

it always works.

  1. The repo reflects true state. Verified numbers only, honest negatives

included.
