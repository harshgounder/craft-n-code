HARDWARE OPTION - NOT a track assumption (archived)

The site's PS-05 "Hardware Hack" is part of the CLUB BACKUP SET (Rudra intel).

The REAL problems come from the sponsor companies. We do NOT build a hardware

pitch unless the released problem itself demands hardware.

If the released problem names sensors/microcontrollers/devices:

  • ESP32 dev board (~400-500 INR, Amazon 1-day)
  • MQ135 air quality sensor (~100 INR)
  • DHT11 temp/humidity (~60 INR)
  • Breadboard + jumper kit (~100 INR)
  • USB data cable (for flashing + serial)

Total: under 1,000 INR, same-day delivery available in Jaipur.

Decision rule: if the drop mentions hardware AND we have a board in hand, the

threshold-breach concept (sensor -> LED + buzzer + dashboard alert +

compliance log) mounts on the shared engine. Otherwise: no hardware, no pitch.
