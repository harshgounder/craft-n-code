WAVE 3: problem-lane evidence mining - what sponsors will set + best topics (idea-lab method)

META

Reader: Team 511 (E&CE 2nd-yr, MUJ), Craft N Code 2026 Rajasthan qualifier Aug 15-16. The problems are written by sponsor companies (Google, Apple, Meta, Accenture, Adobe) - club insider intel. We apply the idea-lab evidence-mining method (from the startup-idea-discovery skill): money flows, complaint mining, workaround detection, second-signal rule, kill criteria. Goal: predict the most likely problem statements + the best solution topics we can pre-build.

Section 1: Evidence mining - what problems are sponsors OBSESSED with in 2026

  • Follow the money: each sponsor's 2025-2026 AI investments, acquisitions, product launches (what they're spending on = what they'll ask students to build)
  • Complaint mining: what developers complain about with each sponsor's APIs/platforms (Reddit, GitHub issues, X) - complaints = problem shapes
  • Workaround detection: what developers hack around in each sponsor's ecosystem (spreadsheets, scripts, manual workflows) - workarounds = product-shaped holes
  • Regulatory clocks: what new laws/rules create forced problems (AI Act, DPDPA India, US AI executive orders)

Section 2: The 5 most likely problem statements (ranked with evidence)

For each: the exact problem text shape, the sponsor likely to set it, the evidence chain (why we think this), the winning solution, the 24h MVP scope, the demo, kill criteria (when to abandon it)

Section 3: The best topics we should pre-build (regardless of problem)

  • The 5 cross-cutting solution patterns that win any AI hackathon
  • For each: the scaffold component, the skin/mount time, the demo script
  • The one-engine-many-skins architecture validated against these topics

Output contract

  • Markdown, 25,000+ characters
  • Inline URLs for every evidence claim
  • Tables for problem ranking
  • Evidence labels [VERIFIED]/[INFERRED]/[UNVERIFIED]
  • Sources section at end
